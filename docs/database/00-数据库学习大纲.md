# 数据库学习大纲

> 目标：建立数据库整体知识地图，先理解“为什么这样设计”，再深入具体数据库和 SQL。

## 1. 数据库基础

- 数据库解决什么问题
- DB / DBMS / Table / Record / Field
- 结构化数据与非结构化数据
- OLTP 与 OLAP
- 数据库在系统架构中的位置

## 2. 数据库分类

### 2.1 关系型数据库

核心特点：

- 表、行、列
- Schema
- 主键 / 外键
- SQL
- JOIN
- 事务
- 约束

重点数据库：

- PostgreSQL
- MySQL
- Oracle
- SQL Server
- SQLite

### 2.2 非关系型数据库（NoSQL）

重点理解：NoSQL 不是“替代关系型数据库”，而是针对不同数据模型和场景的补充。

主要类型：

- Key-Value：Redis
- Document：MongoDB
- Wide Column：Cassandra
- Graph：Neo4j
- Vector Database：Qdrant / Milvus / Weaviate / Pinecone

## 3. 关系型数据库核心模型

重点掌握：

- Table / Row / Column
- Schema
- Primary Key
- Foreign Key
- Unique
- Not Null
- Default
- Constraint
- 一对一 / 一对多 / 多对多

## 5. 索引

## 6. 事务

核心概念：

- Transaction
- ACID
- Commit
- Rollback
- Isolation Level
- Dirty Read
- Non-repeatable Read
- Phantom Read
- Lock
- Deadlock
- MVCC

这一部分是理解后端业务一致性的基础。

重点：

- 如何拆表
- 主键怎么设计
- 外键要不要使用
- 字段类型怎么选
- Normalization
- 反范式
- 冗余字段

## 8. PostgreSQL / MySQL / Oracle

不急着同时深入三种数据库，先理解共同原理，再比较差异。

重点比较：

- 数据类型
- SQL 方言
- 自增主键
- 分页
- JSON 支持
- 索引
- 事务
- 锁
- 执行计划
- 存储过程
- 生态与适用场景

## 9. Redis

先把 Redis 理解成高性能 Key-Value 数据系统。

重点：

- String
- Hash
- List
- Set
- Sorted Set
- TTL
- Cache
- Session
- Counter
- Distributed Lock
- Pub/Sub

进一步再学习：

- 缓存穿透
- 缓存击穿
- 缓存雪崩
- 持久化
- 主从
- Sentinel
- Cluster

## 10. Document Database

以 MongoDB 为代表。

重点：

- Document
- Collection
- JSON / BSON
- Schema Flexibility
- Embedded Document
- Reference
- Index

理解什么情况下文档模型比关系表更自然。

## 11. Graph Database

以 Neo4j 为代表。

核心模型：

```text
Node
+
Relationship
+
Property
```

典型场景：

- 社交关系
- 知识图谱
- 推荐
- 权限关系
- 路径查询

## 12. Vector Database

重点服务 AI / RAG 场景。

核心链路：

```text
Text
↓
Embedding
↓
Vector
↓
Index
↓
Similarity Search
↓
Top K
```

重点概念：

- Embedding
- Vector
- Cosine Similarity
- ANN
- HNSW
- Metadata Filter
- Hybrid Search

常见产品：

- Qdrant
- Milvus
- Weaviate
- Pinecone
- pgvector

## 13. 数据库与后端

数据库最终要和后端工程结合起来理解：

```text
HTTP API
↓
Service
↓
Transaction
↓
ORM / SQL
↓
Database
```

后续需要结合：

- Connection Pool
- ORM
- SQLAlchemy
- MyBatis / JPA
- Migration
- Transaction Boundary
- Read / Write Separation
- Cache
