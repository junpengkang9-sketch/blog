# 数据库基础

> 目标：先建立关系型数据库的最基本认知，能看懂表结构和基础 SQL。

## 1. 基本结构

关系型数据库最常见的结构：

```text
Database
↓
Table
↓
Row
↓
Column
```

- Table：表，一类数据
- Row：一条数据
- Column：一个字段

## 2. 主键、外键、索引

- Primary Key：唯一标识一条数据
- Foreign Key：建立表和表之间的关系
- Index：提高查询速度

## 3. CRUD

```text
Create → INSERT
Read   → SELECT
Update → UPDATE
Delete → DELETE
```

例如：

```sql
SELECT * FROM users;
```

## 4. 常用查询

- WHERE：条件筛选
- ORDER BY：排序
- GROUP BY：分组统计
- JOIN：把有关联的多张表连接起来查询

### GROUP BY

例如按部门统计人数：

```sql
SELECT deptId, COUNT(*)
FROM users
GROUP BY deptId;
```

### JOIN

先不要使用表别名，直接写完整表名更容易理解：

```sql
SELECT users.name, departments.deptName
FROM users
JOIN departments
ON users.deptId = departments.deptId;
```

可以理解为：

```text
张三 deptId=10
+
研发部 deptId=10
↓
张三 研发部
```
